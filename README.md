<h3>This is about "Excel XLOOKUP, Pivot-Table and Basic Dashboard.xlsx" file.</h3>
<p>Here i use XLOOKUP to call data from another sheet and create some pivot table for creating dashboard.
<br>
There have 3 sheets that show some sales related data. I duplicate <b>Sales_Data</b> sheet for doing my work. That new sheet, i calculate <b>Gross_Sales</b> value and <b>Net_Sales</b> value. I do more task that i called <b>Product_Name</b> and <b>Department</b> by XLOOKUP formula.
<br>
After calculating and data called i create 3 <b>Pivot Table</b> like as top 5 product sales, total sales by Branch and total sale by Department. Then i create a simple <b>Dashboard</b> using Pivot table data.
</p>
